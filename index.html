Analisis Logistik & Piutang (SQL)

Studi Kasus Kueri Relasional Data

Deskripsi: Penulisan skrip kueri SQL untuk melakukan pembersihan data (data cleaning), agregasi transaksi, dan audit piutang pembayaran mitra BUMN/TNI/Polri.

SELECT mitra_instansi, SUM(total_tagihan) AS total_piutang
FROM transaksi_bulog
WHERE status_pembayaran = 'UNPAID'
GROUP BY mitra_instansi;
  • Memvalidasi status pembayaran piutang transaksi secara terpusat.
  • Menyaring anomali pencatatan pengeluaran persediaan barang.
